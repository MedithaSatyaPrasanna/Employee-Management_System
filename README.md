Employee Management System

A Python-based Employee Management System developed using Object-Oriented Programming (OOP) concepts.

Features

Add employees

Add Developers and Managers

Display all employees

Search employees by Employee ID

Update employee salary

Remove employees

Prevent duplicate Employee IDs

Validate employee salary

OOP Concepts Used

Encapsulation — Controls access to employee salary.

Abstraction — Uses an abstract Employee base class.

Inheritance — Developer and Manager inherit from Employee.

Polymorphism — Developer and Manager provide their own implementations of methods.

Technologies Used

Python

Object-Oriented Programming

How to Run

Open a terminal in the project folder and run:

python main.py
